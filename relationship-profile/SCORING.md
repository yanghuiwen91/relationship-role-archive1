# 题库与计分规则 v1.0.0

## 题库

完整题目、选项和权重见 `config/questions.json`，内部索引0—7依次为：引导、共同行动、照料、热情表达、情绪理解、稳定经营、自主空间、关系修复。显示顺序与计分方向分离，不在选项旁展示角色或维度。

八类情境各3题：日常陪伴、表达好感、对方低落、自己需要支持、分歧修复、独处边界、共同计划、新鲜稳定。每题四个合理选择，没有标准正确答案。

每选项一个主倾向权重2、一个辅助倾向权重1。题库按八题对称区组组织，三组共24题。每维主权重机会12次、辅助权重机会12次，总24个非零计分机会；累计权重机会总和36。因为同一道题只能选一个选项，理论最大可得分是33，不是36。每维理论最小0。

辅助维度采用对称配置保证机会均衡；这是本趣味测试的设计规则，并不意味着两种倾向在真实人群中存在已验证的统计关联。各选项具体权重可逐项检查 JSON。

## 归一化

对每个维度 d：

```
min[d] = Σ题目 min(四个选项在d上的权重)
max[d] = Σ题目 max(四个选项在d上的权重)
raw[d] = Σ题目 所选选项在d上的权重
score[d] = 100 × (raw[d] - min[d]) / (max[d] - min[d])
```

当前每维均为 `100 × raw / 33`。匹配使用未四舍五入的分数；展示保留1位小数。得分不是人群百分位、心理能力、匹配率或科学诊断。各维不能同时达到100。

## 多维原型

角色顺序为引路人、同行者、守护者、点火者、倾听者、筑巢者、留白者、修桥者。每个角色 i 的原型：自身维度85，循环后第二维55，后一维35，其他维25。完整8×8矩阵在 `config/scoring.json`。这些数值是明确的设计参数，未经过人群常模验证。

匹配距离为8维均方根距离 `sqrt(Σ(score-prototype)² / 8)`。距离最小为主角色，次小为辅助角色；并非简单取最高分维度。

预先规定平分规则：先按精确距离升序，再按该角色对应维度的实际分数降序，仍相同按固定角色索引升序。无随机数、无随机百分比。前两名距离差不大于3时显示“你兼具两种关系倾向”。阈值3是编辑规则，不是统计显著性。

## 解释生成

- 答题依据：每个实际选择对主角色维度的权重×2 + 对辅助角色维度的权重，降序选3条，同分按题号。直接引用题干与真实选择。
- 付出方式：在日常、困难、分歧三类分别选择对主角色倾向贡献最大的一条回答，同分按题号，保留情境和回答。
- 回应、误会、练习来自角色配置；边界句来自辅助角色；28种不同组合拥有独立的互补与张力说明。
- 已完成报告保存到服务端，不因重复提交重算或扣次。

## 可达性证据

`npm test` 为每个目标角色构造选择序列：最大化目标权重×10 + 该角色辅助原型维度权重，并以选项序号确定性破平分。测试验证八种主角色全部可达，输出每种完整答案序列。测试同时检查机会均衡、极值、重复结果、平分、依据真实性和改答后的变化。

该题库是原创趣味内容，不宣称准确率、稀有人格比例、伴侣排名、关系预测或诊断效力。
